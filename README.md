# 🧠 Image Classification using CNN

A deep learning project for classifying images into 10 different categories using a Convolutional Neural Network (CNN) built with TensorFlow and Keras.

The project uses the CIFAR-10 dataset and demonstrates the complete machine learning workflow, including data preprocessing, augmentation, CNN model development, training, validation, evaluation, and prediction.

---

## 🎯 Project Objective

The objective of this project is to build a Convolutional Neural Network capable of automatically identifying and classifying images into one of the 10 CIFAR-10 categories.

This project was developed to gain practical experience with:

- Deep Learning
- Convolutional Neural Networks
- Image preprocessing
- Data augmentation
- Model training
- Model evaluation
- Classification metrics
- Model visualization

---

## 📂 Dataset

This project uses the **CIFAR-10 dataset**, a commonly used benchmark dataset for image classification.

The dataset contains:

- **50,000** training images
- **10,000** test images
- **10 different classes**
- RGB color images
- Image size: **32 × 32 pixels**
